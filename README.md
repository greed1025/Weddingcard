# Abhishek & Anjusha — Wedding Website

A static, mobile-friendly wedding invitation website. No photos or paid services are required.

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — countdown, scroll reveals and mobile navigation

## Preview locally
Open `index.html` in a browser. Internet access is used only for Google Fonts and Google Maps links; the website itself is static.

## Deploy free with Vercel
1. Create a free GitHub account at https://github.com/
2. Create a new repository, for example `abhishek-weds-anjusha`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Sign in at https://vercel.com/ using GitHub.
5. Select **Add New → Project**, import the repository, and deploy.
6. Keep Framework Preset as **Other**. No build command is needed; leave the output directory blank/default.
7. Vercel will provide a public `*.vercel.app` URL.
